Hochladen bei GitHub
====================

Diese Dateien ersetzen die gleichnamigen Dateien im Repository
SimFischer/Theodizee. Die Ordnerstruktur muss erhalten bleiben:

  index.html
  lehrer.html
  README.md
  assets/css/style.css
  assets/js/seiten.js
  assets/js/einheit.js
  assets/js/quelle.js
  assets/js/app.js
  assets/js/druck.js
  assets/js/lehrer.js
  assets/js/storage.js

So geht es im Browser:

1. github.com/SimFischer/Theodizee oeffnen.
2. Oben auf "Add file" > "Upload files" klicken.
3. Den INHALT dieses Ordners in das Feld ziehen - also die beiden
   HTML-Dateien, die README und den Ordner "assets" markieren und
   gemeinsam hineinziehen. Nicht den Ordner "theodizee-upload" selbst,
   sonst landet alles in einem Unterordner.
   (Diese Datei hier, ZUERST-LESEN.txt, bitte nicht mitziehen.)
4. GitHub zeigt an, dass bestehende Dateien ersetzt werden - das ist so
   gewollt.
5. Unten eine kurze Commit-Nachricht eintragen, z. B.
   "Fehler markieren, gestufte Tipps, Freitexte sperren nicht mehr".
6. "Commit changes" klicken.

Neu in dieser Fassung:
- falsche Aufgaben werden rot markiert, der Hinweis steht daran
- Schnellsprung aus der Fehlermeldung in die passende Textstelle
- staerkere Tipps, je oefter dieselbe Aufgabe falsch war
- nur geschlossene Aufgaben sperren die Seite; Freitexte nicht mehr

Die ?v=-Nummern in index.html und lehrer.html sind bereits erhoeht, die
iPads holen sich die neuen Dateien also von selbst.

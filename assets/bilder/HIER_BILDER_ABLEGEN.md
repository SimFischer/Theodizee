# Bilder dieser Einheit

Lege hier deine eigenen Bilddateien ab. Die Anwendung erwartet:

| Datei | Verwendung | Status |
|---|---|---|
| `karikatur.jpg` | Karikatur „Schreckensbilanz" im Einstieg (Lernschritt 1) | **fehlt noch** |
| `naturkatastrophen.jpg` | Reserve-Impuls im Einstieg, aufklappbar | liegt bereit |

Solange eine Datei fehlt, zeigt die Seite an dieser Stelle einen gestrichelten
Kasten mit einem Hinweis statt eines kaputten Bildes — so siehst du sofort,
was noch fehlt.

Andere Dateinamen oder weitere Bilder trägst du in `assets/js/seiten.js` beim
Feld `bild` der jeweiligen Seite ein:

```js
bild: {
  datei: "assets/bilder/meinbild.jpg",
  alt: "Kurze Beschreibung für Screenreader",
  unterschrift: "Bildunterschrift mit Quellenangabe"
}
```

**Urheberrecht:** Lege hier nur Bilder ab, die du für den Unterricht verwenden
darfst. Da die Seite über GitHub Pages öffentlich erreichbar ist, reicht die
Schrankenregelung für den Unterrichtsgebrauch (§ 60a UrhG) unter Umständen
nicht aus — sie setzt einen abgegrenzten Teilnehmerkreis voraus. Im Zweifel
eigene Aufnahmen, lizenzfreie Bilder oder eine Projektion am Smartboard statt
der Einbindung hier.
